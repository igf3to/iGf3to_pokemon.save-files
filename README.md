# Pokémon Save Files

A collection of my personal Pokémon game save files for use with various emulators and game versions. I will be trying to upload all my Pokémon Save files from Gen 1 upto Gen 6(XY).

## About

This repository contains save files for the following Pokémon games:

- **Pokémon FireRed (GBA)**
- **Pokémon LeafGreen (GBA)**

These are for sharing purposes, testing, research, or to help others experience completed games, events, or special Pokémon.  
**No copyrighted ROMs or illegal content is included. Only save files are provided.**

---

## How to Use

1. **Download** a save file from the `saves/` folder.
2. Place it in the correct directory for your emulator or hardware.
3. Load the game and use the save file as your game progress.
   - Example for mGBA:  
     Place `PokemonEmerald.sav` in the same folder as your `PokemonEmerald.gba` ROM, ensuring the filenames match.

**Note:** These save files require the matching version/region of the ROM/game to function.
